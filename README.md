¿string es un tipo por valor o por referencia?
string es un tipo por referencia, aunque se comporta de manera especial porque es inmutable (no puede modificarse una vez creado).
¿Qué secuencias de escape tiene string?
Algunas de las más usadas son:
\n → salto de línea
\t → tabulación
\" → comillas dobles
\\ → barra invertida
\r → retorno de carro
\0 → carácter nulo
¿Qué sucede al usar @ y $ antes de una cadena?
@ → crea una cadena literal, ignorando secuencias de escape.
$ → permite interpolación de cadenas (insertar variables dentro del texto).
@$ o $@ → combina ambas características.
